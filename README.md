## 🚀 Featured Project
 
### 🎓 IIS EduGrade AI — Multi-Agent Assessment System
> **Major Project · BSc (Hons.) Data Analytics & AI · IIS University, Jaipur · 2025–26**
 
**📌 Problem:** Teachers at IIS University manually evaluated student answer sheets — slow, inconsistent, and difficult to scale for NBA accreditation tracking.
 
**✅ What I Built:** An AI-powered web system that automates answer sheet evaluation using a **4-agent pipeline**. Each agent handles a specific task — keyword extraction, keyword matching, semantic evaluation, and final score orchestration. The system also tracks **Course Outcome (CO) attainment** per student, a mandatory NBA accreditation requirement.
 
**💡 Business Value:** Reduces manual evaluation time significantly, standardises scoring across batches, and delivers a downloadable Excel report per session.
 
`Python` · `Flask` · `Groq LLM API` · `SQLite` · `Excel Export`
 
🔗 [**View Project →**](https://github.com/TEENA2004/Multi-Agent-Assignment-System)
